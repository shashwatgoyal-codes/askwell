# Askwell

Browser extensions for asking AI well, published under one developer name: Shashwat Goyal.
The first product is **Preflight** (`apps/preflight`). It checks a prompt on claude.ai, chatgpt.com and
gemini.google.com before it is sent.

## Layout

- `apps/preflight` — the WXT extension (React, TypeScript, Tailwind v4).
- `apps/preflight/lib/sites.ts` — where each chat site keeps its prompt box. When a site redesigns,
  this is the file to fix. The e2e tests serve stand-in pages at the real URLs, so they prove the
  extension works but not that a live site's markup still matches.
- `apps/preflight/lib/improve` — Improve: the instructions and JSON contract every provider must meet,
  and one call per provider through its official SDK, run only from the background worker. The
  Anthropic default model is `claude-opus-5-5` at low effort with server-side fallback; OpenAI and
  Gemini models are picked from the key's own model list rather than hard-coded.
- `docs/` — logo files (`docs/brand`) and README images (`docs/images`). The images are generated by
  `DOCS=1 pnpm --filter @askwell/preflight exec playwright test e2e/docs.spec.ts`; regenerate them when
  the UI changes rather than editing them by hand.
- `packages/rules` — the prompt checks. Plain TypeScript with no browser APIs, so the extension and a
  future Claude Code hook can share them. Every check gets tests.

## Commands

```
pnpm dev            # Preflight in Chrome with hot reload
pnpm build          # production builds
pnpm zip            # Chrome and Firefox zips in apps/preflight/dist
pnpm test           # Vitest
pnpm test:e2e       # builds, then drives Chromium with the extension loaded (Playwright)
pnpm typecheck
```

CI (`.github/workflows/ci.yml`) runs typecheck, unit and browser tests on every push to `main`.
Pushing a `preflight-v<version>` tag runs `release.yml`, which publishes the zips; see README → Release.

## Rules

- **One author.** Commit as `Shashwat Goyal <shashwatgoyaloffice@gmail.com>`. Never add
  `Co-Authored-By` lines for Claude or a "Generated with Claude Code" line; the `commit-msg` hook in
  `.githooks/` refuses them. Commit and push only when asked; pushes use Shashwat's own credentials.
- **No secrets in git.** `.env*` and `*.pem` are ignored, and the `pre-commit` hook refuses secrets
  files and anything shaped like a real API key or private key. Tests use obviously fake keys.
- **Bring your own key.** A user's API key stays in `storage.local` in the extension and goes only to
  the provider. It never reaches a server of ours and is never logged.
- **Checks run locally.** Nothing leaves the browser unless the user clicks Improve. Nudge templates,
  including the session summary, go into the chat the user is already in.
- **No store publishing.** Builds are loaded unpacked; Firefox uses unlisted signing.
- **Design:** neutral near-black, one coral accent (`#FF6B4A` dark / `#D2401F` light), Geist and Geist
  Mono, hairline borders. The mockups are on the design canvas.
